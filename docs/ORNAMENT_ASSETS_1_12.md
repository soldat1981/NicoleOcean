# Иллюстрированные украшения 1.12

Созданы встроенным imagegen, не CLI. Ресурс: `app/res/drawable-nodpi/ocean_ornaments.png`, RGBA 1536×1024, атлас 3×2. Скопирован в проект; приложение не зависит от внешнего каталога генератора. Изображение просмотрено; прозрачность проверена (альфа 0–254). Ячейки выбираются средствами Android Canvas. Мягкое свечение входит в альфа-канал.

Промпт:

> Create a polished 2D underwater mobile game decorative sprite atlas, transparent background. Exactly 3 columns by 2 rows, six separate isolated ornaments centered in equal square cells with wide transparent padding: top row lavender branching coral, turquoise ribbon kelp with golden tips, luminous blue crystal cluster; bottom row pink sea anemone, ancient miniature pearl arch ruin, golden spiral shells with tiny starfish. Soft rounded storybook game art, teal mint lilac peach palette, subtle dimensional shading, charming delicate bioluminescent details, clear silhouettes. No text, no borders, no scenery background, no fish, no people. Uniform cell sizing suitable for splitting a 3x2 atlas in Android Canvas. Save generated asset for game use.

Формы, движения и игровые эффекты выполнены непосредственно в Canvas и сохраняют стиль существующей игры. Фотографии Николь и Босси не отправлялись генератору при создании этих украшений.
