# Видео домашнего рифа

Единый файл: [Home-Reef-Progression.mp4](../dist/reef-video/Home-Reef-Progression.mp4).
88 секунд, 504 × 960, 30 кадров/с, H.264/AAC. Одиннадцать глав по восемь
секунд: обзор постройки и игровой эпизод для каждого состояния 0–10.

Это постановочная демонстрация настоящего движка, а не непрерывное прохождение
кампании и не нейросетевая анимация. Начальные уровни, позиции рыб и таймеры
заданы для съёмки. Далее Game.update работает с частотой 60 Гц, герой управляется
сценарием, рыбы, питание, урон, бонусы и защита используют игровые правила.
Случайные катастрофы и гости отложены, чтобы показать риф. Неуязвимость герою
не добавлялась; в итоговой записи смертей нет. Музыка взята из игры.

Исходник экспортёра: `pc/tools/ReefVideo.java`. После подготовки PC-классов
скомпилировать его с classpath `build/pc/classes` в `build/pc/video`, затем
запустить `com.nicole.ocean.ReefVideo` с объединённым classpath этих каталогов.
Два аргумента: абсолютный путь к FFmpeg и путь выходного MP4.
Экспортёр передаёт кадры напрямую FFmpeg и сохраняет по одному контрольному
PNG на главу рядом с видео. FFmpeg 7.1 поставлен локально через imageio-ffmpeg
0.6.0 в `.tools/video`; глобальная установка не требуется.

Полное декодирование итогового видео FFmpeg завершилось без ошибок.
