# Океан Николь для Windows

Версия 1.16.0, 30 октября 2026. Портативная сборка Windows x64:
[NicoleOcean-PC-Windows-x64.zip](../dist/NicoleOcean-PC-Windows-x64.zip).

Распакуйте архив целиком и запустите `NicoleOceanPC/NicoleOceanPC.exe`.
Папки `app` и `runtime` должны оставаться рядом с программой. Java включена
в комплект. Интернет и Android-эмулятор не нужны. Проверено на Windows 11 x64;
другие версии Windows отдельно не проверялись. Сборка не имеет подписи Authenticode.

## Управление и сохранения

| Действие | Управление |
|---|---|
| Движение | Удерживать левую кнопку — плыть к курсору; либо WASD / стрелки |
| Рывок | Пробел или Shift |
| Пауза / назад | Esc |
| Пауза / продолжить | P |
| Начать, подтвердить обучение, продолжить с паузы | Enter |
| Развернуть / восстановить окно | F11 |
| Кнопки и раскраска | Мышь |
| Прокрутка меню | Колесо мыши или перетаскивание |

Клавиатура имеет приоритет над мышью. Пробел и Shift работают и при движении
мышью. При отпускании левой кнопки, паузе и потере фокуса управление мышью
сбрасывается. Кнопки интерфейса не задают направление движения.

При потере фокуса и сворачивании игра встаёт на паузу, ввод сбрасывается,
звук останавливается. Возврат в окно не снимает паузу автоматически.
Поле сохраняет вертикальную компоновку; широкое окно имеет боковые поля.
Одновременно разрешён один экземпляр игры на профиль.

Профиль находится в `%LOCALAPPDATA%\NicoleOceanPC`: два атомарных файла
`ocean-a.save` и `ocean-b.save`, музыкальные настройки `music.properties`.
Снимок игрового состояния совместим с общим форматом v13; автоматического
переноса с телефона нет. Для резервной копии закройте игру и скопируйте эту папку.
Замена распакованной программы не удаляет профиль. `error.log` записывается при
необработанной ошибке. Проверки сборки создают отдельные временные профили.

## Устройство порта

Модель, правила, сохранения, векторная графика и изображения берутся из
`app/src/com/nicole/ocean` и ресурсов Android-проекта. Все 50 обычных океанов,
10 хранителей, 55 уровней героя, 56 форм обитателей, посетители, опасности,
бонусы и раскраски используют общий код.

`pc/tools/prepare.py` готовит копии исходников в `build/pc/generated`:
заменяет внешнюю Activity оболочкой Windows, добавляет обработчик клавиатуры,
меняет подсказки управления, освобождает Java2D-контекст кэшированного фона.
Редактировать сгенерированные файлы не нужно.

`pc/src/android` — небольшой слой совместимости используемых рисующих API
на Java2D/Swing, а не Android runtime. `pc/tools/create_graphics.py` содержит
его исходный генератор; при изменении адаптеров обновляйте и генератор.
Windows-оболочка, звук Java Sound и тесты находятся в `pc/src/com/nicole/ocean`.
Музыка и реплики загружаются вне потока интерфейса; отменённая загрузка не
запускает звук после паузы. Звук и музыка имеют отдельные переключатели.
Небольшое изменение высоты звуков еды из Android SoundPool на PC не применяется.

## Повторная сборка

Нужны Python 3 и Windows x64 JDK 20 с `javac`, `jar`, `jlink`, `jpackage`:

```powershell
.\build-pc.ps1 -JavaHome 'C:\Program Files\Java\jdk-20'
```

Скрипт компилирует приложение, выполняет тесты PC и три набора общих модельных
тестов, создаёт JAR, сокращённую Java со встроенными лицензиями, папку с EXE
и ZIP. Установщик MSI и WiX не требуются. `-SkipPackage` запускает компиляцию
и тесты без создания EXE. Иконка уже находится в `pc/NicoleOcean.ico`.
В ограниченной среде Codex проверка доступности каталога в `jpackage` может
потребовать разрешённого запуска упаковщика за пределами sandbox.
